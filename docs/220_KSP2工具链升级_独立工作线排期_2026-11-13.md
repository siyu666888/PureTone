- **官方兼容性**（§六 6.2 已核实）：Room **2.7.0** 才「Support for KSP2 is also added and is recommended」，Room 2.6.x 与 KSP2 不能共存；Dagger/Hilt 的 KSP2 崩溃到 **2.53.1** 才修。当前两个 processor 都不支持 KSP2。

- **联动面**：KSP 版本前缀须与 Kotlin 对齐；Room 2.7 的 KMP 重构 / Kotlin CodeGen 默认开启 / `room-ktx` 合并 / schema 导出行为变化；Hilt DI 注解生成类名变化；手写 `baseline-prof.txt` 类名可能被 AGP 静默丢弃；Compose compiler、detekt、lint FIR 缓存、CI 26 步、16KB/LGPL/apksigner 全部要重验。
