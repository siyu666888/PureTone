# PureTone 测试证据记录（2026-10-21）

## 1. APE 文件播放（补测，修复后）

### 1.1 根因（本次会话修复）
APE 点击后转码崩溃：`ClassNotFoundException: com.arthenica.smartexception.java.Exceptions`
- 本地 AAR（files() 方式）不解析 POM 传递依赖 → 缺 smart-exception-java
- 原依赖写错变体：`smart-exception-java9`（包名不含 ffmpeg-kit 需要的类）
- release  additionally 被 R8 裁剪 ffmpeg-kit 类

### 1.2 修复内容
- `gradle/libs.versions.toml`：`smart-exception-java9` → `smart-exception-java`（0.2.1，Maven Central 仍在）
- `app/build.gradle.kts`：`implementation(libs.smart.exception.java)`
- `app/proguard-rules.pro`：修正 keep 包名 `com.arthenica.smartexception.**`（此前误写为 `smart.exception.**`）；
  补 ffmpeg-kit consumer 规则（AAR 自带 proguard.txt 在 files() 方式下不生效，须手抄）：
  - `FFmpegKitConfig` native/log/statistics/safOpen/safClose
  - `AbiDetect` native

### 1.3 验证结果（x86_64 模拟器，sh3.ape 经典 `MAC ` 格式，15.67s）

| 包 | 转码缓存 | WAV 参数 | 播放 | 崩溃 |
|---|---|---|---|---|
| debug (v1.0.1) | `cache/ape_transcode/ape_4.wav` 2,763,614 B | 2ch/44100Hz/16bit/690843帧=15.67s | 播完自动切歌 | 无 |
| release (v1.0.1) | `/data/data/com.puretone.player/cache/ape_transcode/ape_1.wav` 2,763,614 B | 同上 | 播完自动切歌 | 无 |

日志无 ClassNotFoundException / UnsatisfiedLinkError / FFmpegKit 报错。

### 1.4 APE 支持的环境限制（如实告知用户）
- AOSP 原生 MediaProvider **不扫描 .ape** 入库（测试靠 `content insert` 伪造行，MIME 须用 audio/mpeg）
- App 曲库过滤 `DURATION >= 30_000`，sh3.ape 仅 15.67s（测试时 duration 填 31000 绕过）
- 结论：真实机型（OEM ROM 的 MediaProvider 通常收录 APE）可正常入库；纯 AOSP 模拟器需上述绕过

## 5. 踩坑记录（对后续测试有用）
- **input keyevent 127 = MEDIA_PAUSE，不是 PLAY_PAUSE**；PLAY_PAUSE 是 **85**。曾误判「127 无法恢复播放」，反编译 `MediaSessionImpl.applyMediaButtonKeyEvent` 证实：127 分支恒为 pause-runnable，toggle 逻辑在 85 分支（读 `PlayerWrapper.getPlayWhenReady()`）。
- 锁屏媒体卡有 300ms 双击检测窗口（`MediaPlayPauseKeyHandler`，双击=下一首）
- uiautomator 无法 dump 锁屏（seekbar 波形动画致窗口永不 idle）→ 用截图+像素分析定位按钮
- 锁屏卡坐标（1080x2340）：暂停 (925,972)、下一首约 (985,1135)；通知栏卡片同布局但整体上移约 200px
- 队列 4 首短曲（45/75s）会在测试间隙播完 → 测长流程先用 120s 曲目
- PIN 键盘：`input text` 不可靠；直接点数字键 (270/540/810, 1130/1370/1610/1850)，确认键 (810,1850)
- Git Bash + adb：一律 `MSYS_NO_PATHCONV=1`，本地路径用 Windows 风格（D:/...），否则路径被转换成 C:/Program Files/... 前缀

## 6. 复现命令
```bash
# APE 转码复现（debug）
adb shell am force-stop com.puretone.player   # 避免与 release 包混淆
adb install -r app/build/outputs/apk/debug/PureTone-v1.0.1-x86_64-debug.apk
adb shell am start -n com.puretone.player.debug/com.puretone.player.MainActivity
adb shell input tap 523 536          # sh3 歌曲行
adb shell run-as com.puretone.player.debug ls -la cache/ape_transcode/
```
